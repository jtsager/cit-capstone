# CIT Capstone Project Planning

Author: Jackson Sager

This repository will contain my CIT capstone project for the term.  
Right now, I am still in the early planning stage, so there is no working code yet.  

My current idea is to build a React-based application that lets users create tasks, organize them by category, and track what they’ve completed.

As the project develops, I plan to add:
1. React components for different parts of the interface  
2. State to manage user data and interactions  
3. Lists to display multiple items like habits, tasks, or entries  

I will update this README as the project progresses
